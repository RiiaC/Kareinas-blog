[[2026-04-04 a visit to Luleå|2026-04-04]]
While visiting Kakwkylla and Styrmir I helped them start a new tunic for him. I used the same four body rectangles approach with skirt triangles between that I used for  so many tunics, like the one I helped with for [[Ranghilds orange twill dress]]. But in this case, the fabric was narrow, so it took some careful planning to work out the cutting diagram so that there was enough for everything, but no waste either.

After I cut it I finished the neckline, using the period needle I bought at Drachenwald Coronation 

![[2026-04-04 period needle.jpg]]
I also did the seams at the shoulders.
